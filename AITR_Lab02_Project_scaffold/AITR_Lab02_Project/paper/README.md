# Paper materials

Store the manuscript source (`.tex`), bibliography (`.bib`), and final figures here after method and results are finalized.

Suggested outline: Abstract (write after results), Introduction, Related Work and Taxonomy Mapping, Dataset/Annotation, Methods/Baselines, Experimental Setup, Results (measured only), Error Analysis/Evidence Audit, Limitations/Ethics/Reproducibility, Conclusion.

Cite original sources accurately; do not present planned hypotheses as findings or include unverified numbers.
