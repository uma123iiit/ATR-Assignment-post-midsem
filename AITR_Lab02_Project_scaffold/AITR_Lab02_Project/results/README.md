# Results

This directory intentionally contains no fabricated scores, logs, or figures.

Each completed run should have a unique directory such as `results/<run_id>/` containing the frozen config and Git commit, command and environment/package versions, dataset/split IDs, model identifier/version, metric JSON/CSV with sample counts, permissible predictions, logs, generated figures, and deviations. Add results only after the relevant experiment has actually run. Clearly label synthetic mock data.
