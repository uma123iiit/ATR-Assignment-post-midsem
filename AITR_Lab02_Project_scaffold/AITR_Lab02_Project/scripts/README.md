# Experiment entrypoints

Planned entrypoints, to be implemented and tested when the experimental choices are finalized:
- `train.py`: optional model fitting using a config.
- `predict.py`: produce predictions with model/config identifiers.
- `evaluate.py`: evaluate saved predictions against adjudicated labels and write genuine metrics.
- `run_experiment.sh`: optional orchestration wrapper.

Do not create output files that look like real results until their experiment has run.
